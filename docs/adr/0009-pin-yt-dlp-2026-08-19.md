# 0009. Pin yt-dlp 2026.08.19 to cut media-download 403s

Status: Accepted (2026-10-13)

## Context
On yt-dlp 2026.07.04, audio and video downloads failed with `HTTP 403` in 9 of 9 runs. On 2026.08.19 about half succeed. Passing and failing runs used the same client, format and server, so the refusal comes from YouTube and varies by request.

## Decision
Pin `yt-dlp==2026.8.19` in `requirements.txt`.

Rejected: a retry loop on 403 and a PO-token provider plugin, to keep the tool simple.

## Consequences
Some downloads still get a 403, but re-running usually works, and the metadata and transcript are saved before any download starts. Upgrading yt-dlp is the main fix when YouTube changes again.
